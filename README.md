# Artora by FramEmpire 🎨✨
> **Fine Art & Acrylic Canvas Creations by Fiha Islam**

Artora is a futuristic, luxury fine art eCommerce web application built with **Next.js 15 (App Router)**, **Tailwind CSS**, **Framer Motion**, **Three.js**, **Prisma**, and **next-intl (Bilingual: Bengali & English)**.

---

## 🌟 Key Highlights & Features

- **Minimalist Futuristic Luxury Design:**
  - Deep space maroon (`#0D0004`), polished crimson-black gradients (`#2B020A`), metallic magenta-red accents (`#E60049`), and soft neon ambient lighting (`#FFB0C1`).
- **Interactive 3D Impasto Canvas Studio (Three.js):**
  - Real-time 3D interactive viewer simulating raised acrylic palette knife ridges, tactile canvas texture, and 24k gold leaf specular reflections under orbiting spotlights.
- **Modern Cinematic Exhibition Gallery:**
  - Interactive category selector, dynamic 8-column focal canvas spotlight with color palette swatches, dimensions metadata, and curator's thumbnail deck.
- **Artist Profile Section:**
  - Dedicated about section highlighting **Fiha Islam** (Founder & Fine Artist), studio metrics, and signature statement.
- **Custom Commission Studio:**
  - 4-step interactive bespoke commission customizer with dynamic real-time BDT pricing calculator, palette selector, and wall photo uploader.
- **Bilingual Experience (`next-intl`):**
  - Full support for **Bengali (Bangla)** with custom **Hind Siliguri** typography, and **English** with Space Grotesk display typography.
- **Dual Payment & Logistics Architecture:**
  - **Bangladesh:** bKash Direct, Nagad Online, SSLCommerz, and Pathao Courier COD with division shipping rate calculator.
  - **Global:** Multi-currency USD toggle, Stripe International Card processing, and DHL/FedEx worldwide crate packaging.

---

## 🛠️ Technology Stack

- **Framework:** Next.js 15 (App Router, Turbopack, Server Components)
- **Styling:** Tailwind CSS + Custom Design System
- **3D Graphics:** Pure Three.js + OrbitControls WebGL Engine
- **Animations:** Framer Motion + Lucide Icons
- **Database & ORM:** Prisma ORM (SQLite / PostgreSQL ready)
- **Localization:** next-intl (Bilingual `bn` default & `en`)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/pabeledp/Artora.git
cd Artora
```

### 2. Install dependencies
```bash
npm install
```

### 3. Database Setup
```bash
npx prisma db push
node prisma/seed.js
```

### 4. Run Development Server
```bash
npm run dev
```
Visit `http://localhost:3000` in your browser.
